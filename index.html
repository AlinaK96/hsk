1. Время и длительность

在 + V + 呢 — действие прямо сейчас

Форма Структура Пример
✅ 在 + V + 呢 我在看书呢。
❌ 没在 + V 我没在看书。
❓ 在 + V + 吗？ 你在看书吗？
Метка: 🗣️✍️ Отрицание только через 没.
Варианты: 正在 + V + 呢 (формально), 正 + V + 呢 (акцент на моменте)

刚 / 刚才 / 才 — только что, только лишь

Конструкция Значение Пример
刚 + V только что (недавно) 他刚走。
刚刚 + V только что (усиление) 他刚刚走。
刚才 + V только что (время) 他刚才走了。
才 + V только лишь (поздно) 他八点才来。
刚 / 刚刚 刚才
Часть речи наречие сущ. времени
Позиция перед V перед подлежащим
С 了 ❌ обычно без 了 ✅ можно с 了
Пример 他刚走。 他刚才走了。

要……了 / 快要……了 / 就要……了 — скоро

Форма Структура Пример
✅ 要 + V + 了 要下雨了。
✅ 快要 + V + 了 快要下雨了。
✅ 就要 + V + 了 就要下雨了。
❌ 还没 + V + 呢 还没下雨呢。
Конструкция Оттенок Со временем?
要……了 скоро ✅ 明天要下雨了。
快要……了 вот-вот ❌ *明天快要下雨了。
就要……了 вот-вот ✅ 明天就要下雨了。
Другие способы будущего: 会 + V (буду), 将 + V (формально), 打算 + V (планировать), 准备 + V (собираться)

都……了 — уже

Форма Структура Пример
✅ 都 + 了 都十二点了。
❌ 还没……呢 还没到十二点呢。
❓ 都……了吗？ 都十二点了吗？
都八点了，你怎么还没起床？Уже 8 часов, почему ты ещё не встал?
他都学了三年汉语了。Он уже три года учит китайский.

先……再 / 又 / 然后…… — сначала…, потом…

Форма Структура Пример
✅ 先 + V1，再 + V2 先洗手，再吃饭。
✅ 先 + V1，又 + V2 先吃饭，又看电视。
✅ 先 + V1，然后 + V2 先学习，然后休息。
Слово Когда Пример
再 будущее / план 先洗手，再吃饭。
又 прошлое 先吃了饭，又看了电视。
然后 универсально 先学习，然后休息。

2. Выделение и акцент

是……的 — выделение обстоятельства

Форма Структура Пример
✅ 是 + X + V + 的 我是昨天来的。
❌ 不是 + X + V + 的 我不是昨天来的。
❓ 是 + 什么时候/在哪儿/怎么 + V + 的？ 你是什么时候来的？
Метка: 🗣️✍️ Действие уже произошло. Выделяет: время, место, способ, цель.
Что выделяем Пример Перевод
Время 我是昨天来的。 Я приехал вчера.
Место 我是在北京出生的。 Я родился в Пекине.
Способ 我是坐飞机来的。 Я прилетел на самолёте.
Цель 我是来学习的。 Я приехал учиться.
С кем 我是跟他一起去的。 Я ходил вместе с ним.

3. Сравнение

比 — сравнение

Структура: A + 比 + B + (更/还) + Adj / V + 补语

Форма Структура Пример
✅ A 比 B + Adj 他比我高。
✅ A 比 B + 更/还 + Adj 他比我更高。
✅ A 比 B + V + 得 + 补语 他比我跑得快。
❌ A 不比 B + Adj 他不比我高。
❌ A 没有 B + Adj 他没有我高。
❓ A 比 B + Adj + 吗？ 他比我高吗？
❓ A 比 B + Adj + 不 + Adj？ 他比我高不高？
Правило: ❌ нельзя 很/非常/太 перед Adj: *他比我很高. ✅ можно 更, 还, 一点儿, 一些, 得多.
Отрицание Значение
不比 не более (может быть равен или ниже)
没有……那么/这么 не такой…, как…

跟……一样 — такой же, как…

Форма Структура Пример
✅ A 跟 B 一样 我跟他一样。
✅ A 跟 B 一样 + Adj 我跟他一样高。
❌ A 跟 B 不一样 我跟他不一样。
❓ A 跟 B 一样 + 吗？ 你跟他一样高吗？
Варианты: 和……一样, 像……一样, 跟……差不多

4. Дополнения (补语)

V + 得 + 补语 — дополнение состояния

Форма Структура Пример
✅ V + 得 + 很 + Adj 他跑得很快。
✅ V + 得 + 不 + Adj 他跑得不快。
❓ V + 得 + Adj + 吗？ 他跑得快吗？
❓ V + 得 + Adj + 不 + Adj？ 他跑得快不快？
❓ V + 得 + 怎么样？ 他跑得怎么样？
Разделяемые глаголы: V + O + V + 得 + Adj
他写字写得很好。 · 他唱歌唱得很好。

V + 着 — состояние

Форма Структура Пример
✅ V + 着 他站着。
✅ V + 着 + 呢 他站着呢。
✅ 处所 + V + 着 + O 墙上挂着一张画。
❌ 没 + V + 着 他没站着。
Типичные: 站着, 坐着, 躺着, 拿着, 穿着, 开着, 关着, 挂着, 放着

Adj + 极了 — чрезвычайно

Форма Пример
✅ 好极了！
❌ 不 + Adj + 极了
Типичные: 好极了, 棒极了, 累极了, 饿极了, 美极了

Adj + 坏了 — ужасно (разг.)

Форма Пример
✅ 我累坏了。
❌ 不 + Adj + 坏了
Типичные: 累坏了, 饿坏了, 急坏了, 吓坏了, 高兴坏了

5. Модальные глаголы

Слово Пиньинь Значение Сила Отрицание
应该 yīnggāi следует, должен средняя 不应该
必须 bìxū должен, обязан сильная 不必 / 不需要
得 děi нужно, придётся сильная, разг. 不用 / 不必
需要 xūyào нужно, требуется нейтральная 不需要
只好 zhǐhǎo приходится вынужденность —
你应该多休息。Тебе следует больше отдыхать.
你必须去。Ты обязан пойти.
我得走了。Мне нужно идти.
我需要帮助。Мне нужна помощь.
下雨了，只好在家。Пошёл дождь, приходится остаться дома.

6. Наречия и степени

挺……的 — довольно

Форма Структура Пример
✅ 挺 + Adj + 的 他挺高的。
✅ 挺 + V + 的 我挺喜欢他的。
❌ 挺 + 不 + Adj + 的 他挺不好的。
Правило: 的 обязателен в конце!
Конструкция Степень Пример
有点儿 немного (негатив) 有点儿贵
比较 довольно 比较好
挺……的 довольно (разг.) 挺好的
很 очень 很好
非常 очень (книжн.) 非常好
太……了 слишком 太好了

越来越…… — всё более

Форма Структура Пример
✅ 越来越 + Adj 天气越来越热。
✅ 越来越 + V(псих.) 我越来越喜欢中国菜。
❌ 越来越 + 很 + Adj *越来越很高
Разница: 越来越 — изменение во времени. 越……越…… — зависимость (越学越难).

疑问词 + 都/也 — обобщение

Конструкция Перевод Пример
谁都 все 谁都知道。
什么 + 都 всё 我什么都吃。
哪儿 + 都 везде 他哪儿都去过。
谁 + 也 + 不/没 никто не… 谁也不知道。
什么 + 也 + 不/没 ничего не… 我什么也没买。
Правило: 都 — утверждение; 也 — отрицание.

7. Союзы и сложные предложения

因为……所以…… — причина → следствие

Форма Структура Пример
✅ 因为 + A，所以 + B 因为下雨，所以我没去。
❓ 为什么……？ 你为什么没去？

虽然……但是…… — хотя…, но…

Форма Структура Пример
✅ 虽然 + A，但是 + B 虽然下雨，但是我去了。
Варианты: 虽然……可是……, 尽管……但是……

如果……就…… — если…, то…

Форма Структура Пример
✅ 如果 + A，就 + B 如果下雨，我就不去。
Варианты: 要是……就……, 假如……就……, 的话

只要……就…… — стоит только…, и…

Форма Структура Пример
✅ 只要 + A，就 + B 只要努力，就能成功。
❌ 只要 + A，才 + B —
Конструкция Тип условия Пример
只要……就…… достаточное 只要努力，就能成功。
只有……才…… необходимое 只有努力，才能成功。
如果……就…… гипотетическое 如果努力，就能成功。

除了……以外 — кроме

Форма Структура Пример
✅ 除了……以外，……都 除了他以外，我们都去了。
✅ 除了……以外，……还/也 除了汉语以外，他还学英语。
Тип Значение Вторая часть Пример
Исключение кроме (не включая) 都 除了他以外，我们都去了。
Добавление кроме (включая) 还/也 除了他以外，我也去了。

又……又…… — и…, и…

Форма Структура Пример
✅ 又 + A + 又 + B 她又聪明又漂亮。
Варианты: 既……又……, 一边……一边……, 也……也……

一……就…… — как только…, так сразу…

Форма Структура Пример
✅ 一 + V1，就 + V2 我一回家就睡觉。
Варианты: 刚……就……

一边……一边…… — одновременно

Форма Структура Пример
✅ 一边 + V1 + 一边 + V2 他一边吃饭一边看电视。
Разница с 又……又……: 一边……一边…… — два процесса; 又……又…… — два качества.

而且 / 并且 — к тому же

Конструкция Значение Пример
而且 к тому же 他会说汉语，而且说得很好。
并且 и, к тому же (книжн.) 他学习努力，并且很聪明。
而 а, но (контраст) 我喜欢茶，而他喜欢咖啡。
并 и (перед 不/没) 他并没生气。

8. Глагольные конструкции

动词重叠 — повторение глаголов

Форма Структура Пример
✅ AA V + V 你看看。
✅ A一A V + 一 + V 看一看
✅ A了A V + 了 + V 看了看
✅ ABAB AB + AB 商量商量
✅ AB了AB AB + 了 + AB 考虑了考虑
✅ AAB A + A + B 见见面
✅ A了一下 V + 了一下 考虑了一下
Ограничения: ❌ нельзя с 正在 · ❌ нельзя с 一边...一边... · ❌ нельзя с дополнением результата

形容词重叠 — повторение прилагательных

Форма Структура Пример
✅ AA A + A 好好
✅ AABB A + A + B + B 高高兴兴
✅ ABAB AB + AB 雪白雪白
✅ A里AB A + 里 + AB 糊里糊涂

9. Выражение мнения

关于 — о, насчёт

Форма Структура Пример
✅ 关于 + тема，…… 关于这个问题，我有意见。
✅ ……关于 + тема 我看了一本书，关于中国历史。
关于 vs 对于: 关于 — тема; 对于 — объект отношения.

对……感兴趣 — интересоваться

Форма Структура Пример
✅ 对 + O + 感兴趣 我对汉语感兴趣。
❌ 对 + O + 不感兴趣 我对足球不感兴趣。
❓ 对 + O + 感兴趣 + 吗？ 你对汉语感兴趣吗？

什么的 / 等等 / 之类的 — и так далее

Конструкция Перевод Пример
什么的 и тому подобное 苹果、香蕉什么的
等等 и так далее 苹果、香蕉等等
之类的 что-то в этом роде 苹果、香蕉之类的
以及 а также 苹果以及香蕉

看起来 / 看上去 — казаться

Конструкция Перевод Пример
看起来 судя по виду 他看起来很累。
看上去 выглядеть 她看上去很年轻。
看起来 + 好像 похоже, что… 看起来好像要下雨。

能……吗？ — разве можно…?

Форма Структура Пример
✅ 能 + V + 吗？ 我能不去吗？
✅ 能 + 不 + V + 吗？ 他能不来吗？
❓ 怎么能 + V + 呢？ 我怎么能不去呢？
Два значения: реальный вопрос / риторический.

还是……吧 — лучше уж…

Форма Структура Пример
✅ 还是 + V + 吧 我们还是走吧。
✅ 还是 + 不 + V + 吧 还是不去吧。

10. Приблизительность

左右 — около

Форма Структура Пример
✅ Число + 左右 三十岁左右
✅ Время + 左右 三点左右
❌ 左右 + Число —
Похожие: 大概 (перед числом), 差不多, 几, 多, 来

各种各样 — разнообразный

Форма Структура Пример
✅ 各种各样 + 的 + N 各种各样的人
Похожие: 各种, 多种多样, 各式各样

11. Пассив и 把

把-конструкция

Форма Структура Пример
✅ 把 + O + V + 了 我把书买了。
✅ 把 + O + V + 补语 他把作业做完了。
❌ 把 + O + 不 + V —
Правило: после 把 глагол не может стоять один.

被-пассив

✅ 被 + B + V + 了 书被他拿走了。
✅ 被 + V + 了 他被打了。
❌ 被 + 不 + V —
